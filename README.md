# ✨ Overview

Srijan Dev is a next-generation futuristic developer portfolio designed to deliver a premium recruiter experience through immersive animations, live project previews, cinematic UI interactions, and modern SaaS-inspired design systems.

The portfolio was engineered to go beyond traditional portfolio websites by integrating:

- Real live project previews
- Interactive developer terminal
- AI-inspired visual systems
- Premium glassmorphism aesthetics
- Dynamic command palette
- Downloadable ATS resume
- Responsive cinematic layouts
- Recruiter-focused architecture

# 🛠️ Installation

## Clone Repository

```bash
git clone https://github.com/srijansk13/portfolio.git
```

---

## Navigate into Project

```bash
cd portfolio
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```
